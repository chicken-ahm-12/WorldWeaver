# WorldWeaver Documentation

WorldWeaver is a procedural Roblox terrain generator built around layered noise, biome selection, interpolation, blending, and optional Roblox Terrain rendering.

Open `index.html` to browse the documentation. The site is static and requires no documentation build step.

## Documentation includes

- Getting started
- Recommended Roblox project structure
- Argon setup and build workflow
- Complete settings reference
- Noise and interpolation configuration
- Biome configuration
- Performance and generation practices
- API reference
- Rendering examples
